Set of debugging tools to make developing and testing mods easier.
-
### **What does the mod do?** 

The mods add an in-game database viewer that can be used whilst in raid to spawn items. It also features a debug menu that has several utilities, as well as developer commands for the console and the freecam from Fika.
This is not meant to be installed on a normal installation as it might directly affect performance.

### **Features**

- Free cam (**F9** in raid by default)
- Database Viewer (**F10** by default)
	- High performance
	- Does not lock the game while searching
	- Supports modded items
	- Can only spawn items in raid
- Debug menu (**F11** by default)
	- God mode
	- Heal
	- Suicide
	- Spawn Airdrop
	- Go to BTR
	- Spawn AI
	- Destroy limb
	- Bring all AI
	- Despawn all AI
- Console commands
	- All of the debug menu tools included as commands
	- RecreateBackend (reloads the backend in the main menu)
	- StopTimer (stops the in-raid timer from counting down)
	- Clear (clears console output)
- Options to show all **Unity.Debug** logs
